# Тірі батарея — «3 ҒЫЛЫМ – 1 ШЕШІМ»

CLIL кіріктірілген сабақтар қалалық фестивалі, «Тұрақты даму мүддесіндегі әріптестік» (ТДМ 17).
Бағыты: Цифрлық технологиялар және инновациялық шешімдер.

**Команда:** Алматы қаласы, Алатау ауданы, №152 мектеп-гимназия
- Тилеухан Ақнұр Рахманалиқызы — физика
- Рамбергенова Багила Аскарызы — биология
- Карибаева Камшат Ахылбаевна — химия

## Сайтта не бар
- Өсімдік-микробтық отын элементінің айналатын 3D моделі (4 құрастыру қадамы)
- 3D қабаттар моделі және «Жасыл Вольт» саябақ модулінің 3D сахнасы
- Сандық зертхана: кернеу, ток, қуат симуляторы
- ЖИ компоненті, «ЖИ қатесін тап» тапсырмасы, нақты промпттар
- CLIL: 4C, үштілді глоссарий, тілдік құрылымдар
- Сабақ жоспары, кернеу күнделігі, тест, бағалау критерийлері

## Жариялау
Бұл — бір файлдан тұратын статикалық сайт (`index.html`), құрастыру қажет емес.
- **Vercel:** репозиторийді импорттаңыз, Framework Preset — *Other*, қалған баптауларды өзгертпеңіз.
- **GitHub Pages:** Settings → Pages → Branch: `main`, папка: `/ (root)`.

3D модель Three.js кітапханасын cdnjs.cloudflare.com сайтынан жүктейді, сондықтан интернет қажет.
